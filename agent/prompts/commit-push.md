Commit and push the current change. Invoking this command authorizes those actions.
Optional Conventional Commit scope: $1.

Inspect staged and working changes, project rules, and recent history. Include only the
requested change; ask if its scope or destination is unclear. Stage explicit paths,
use a short imperative Conventional Commit subject, and omit bot attribution and
Co-authored-by trailers. Push normally to the confirmed remote/branch; never force-push.
Report the commit and push results. Preserve unrelated edits and staged changes.
